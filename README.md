# Vice Coast 3D — Deployment-Ready Open-World Package

## النشر الفوري على الويب (Instant Web Deployment)
ارفع محتويات هذا الأرشيف مباشرةً (مع بقاء `index.html` في المجلد الرئيسي) إلى أي من المنصات التالية:
- **GitHub Pages:** ارفع الملفات إلى المستودع ثم فعّل `Settings > Pages > Branch: main / (root)`.
- **Netlify Drop / Vercel / itch.io:** اسحب ملف الـ ZIP أو مجلد المشروع مباشرةً للنشر خلال ثوانٍ.

## محتويات الحزمة الكاملة
- `index.html`: النسخة ثلاثية الأبعاد الكاملة القابلة للعب مباشرة على الموبايل والكمبيوتر (مدينة 64 بلوك، شخصيات وأسلحة وسيارات GLB واقعية، قارب سريع، متجر ملابس وفنادق تفاعلية، فيزياء اصطدام، هاتف ذكي بـ 8 تطبيقات، وعداد سرعة ودواسات قيادة).
- `manifest.webmanifest`: ملف PWA لتثبيت اللعبة بملء الشاشة على الهواتف.
- `Unity_Blender_Source/`: كامل مشروع Unity (C# + URP Wet Asphalt Shader) وسكربتات Blender 4.x وبرومبتات Higgsfield AI.
